This session runs on a Fly.io machine (Linux, 4 GB), the last resort for when neither the Pi nor the Mac could take it. It has git, gh, flyctl and the supabase CLI, all signed in, and checkouts of Jared's repos under ~/repos cloned from GitHub; push your work, because this machine's disk is not where anything lives. It has no browser, no Remote Control, no Xcode, and no SSH to the Mac or the Pi. iOS builds go through the repo's GitHub Actions workflow. Work that needs his signed-in browser (a cart, an order, a booking) cannot be done here: say so plainly rather than attempting it. The machine stops itself once no session has run for a while, so do not start long-lived background services here.
