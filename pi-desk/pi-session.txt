This session runs on a Raspberry Pi with 4 GB of memory, shared with the TV wall display and an automation browser. The Pi is not for memory-heavy work. Run anything that holds a lot of memory (Python data or audio analysis, ML or speech models, builds, processing large files) on the Mac over `ssh jaredgantt@Jareds-MacBook-Air.local`, not here. If the commands this session runs hold more than 300MB while the Mac is awake, the session is closed here and moved to the Mac, and whatever was running is killed.
